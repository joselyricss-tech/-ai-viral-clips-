
# AI Viral Clips

Plataforma web para analizar videos y encontrar los mejores momentos para crear clips virales.

## Funciones planeadas

- Analizar videos publicados de YouTube.
- Analizar transmisiones en vivo autorizadas.
- Detectar momentos destacados.
- Crear clips verticales en formato 9:16.
- Preparar contenido para TikTok, YouTube Shorts, Instagram y Facebook.

## Tecnologías

- Next.js
- React
- TypeScript
- Python
- FastAPI

## Instalación

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
